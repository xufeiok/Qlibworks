## 1. 执行摘要（最高信号结论）

| # | 结论 | 关键数字 | 性质 |
|---|---|---|---|

**共性提炼：**
1. **挖掘工业化**：要么 Two Sigma/Jump 式平台化（data-as-code、每天数万次模拟），要么 WorldQuant 式算子库枚举（三轴计划），单点灵感式研究被淘汰。
2. **"少而硬"vs"多而散"两条路线并存**：AQR/FF 押注少数经百年验证的溢价；WorldQuant/RenTec 堆叠海量弱信号（百万级 alpha、4k 多/4k 空）。两条路都成立，但**都拒绝"中间态"——几十条来源不明、互相高相关的因子**。
3. **命名/登记纪律在工程层而非信号层**：六家无一家公开信号命名规范；可证的纪律是 Two Sigma 的 feature 版本化 + WW BRAIN 的时间戳/归属人登记 + IQC 团队合并按时间戳倒序做相关性清洗。
4. **数据即资产**：另类数据（新闻文本、天气、传感器）是增量 alpha 的主要来源；Qlibworks 的 sentiment 家族为 0，对应"文本/另类"这条轴完全空白。

**共性提炼：**
1. **没有任何一家公开"IC>0.05/t>2"这类朴素门槛**——这类数字属行业说法；可钉死的是：Medallion 三原则、DE Shaw 的 OOS+同行评审双闸门、WW BRAIN 的 Sharpe>1.25/Fitness>1/Self-corr<0.7、学术界的 t>3.0。
2. **去冗余的公开标尺只有 WorldQuant 给出**：平均两两相关 15.9%——"低相关堆叠"流派的实测水位，0.70 只是拒收红线。
3. **样本外纪律是第一性的**：DE Shaw "不要在自己数据集里赚钱"、WW IQC "qualify for OOS testing 才计分"、AFML 的 purged/embargo——三家独立来源指向同一件事。
4. **IC/t 本身不够，必须对"试验次数"记账**：DSR/PBO/Bonferroni 都是为"试了 m 个才选出 1 个"这个事实付代价。

**共性提炼：**
1. **权重哲学两层**：Two Sigma/WW 是"独立预测→共识/优化器"显式路线；Medallion 是"单一黑箱直接出仓位"。Qlibworks 用 tree model 合成，接近前者，但缺显式风险约束（行业/市值中性化）。
2. **拥挤度两种范式**：Medallion 用执行隐蔽化；Man/MSCI 用集体 beta + 估值价差主动降权。周频 A 股不可能靠打散时间隐蔽，应走 Man 路线。
3. **因子择时普遍被否定**（AQR "siren song"、Man "timing factors is hard"）；跨因子分散 + 波动率归一 + 不押注单一长期 edge 是共识。
