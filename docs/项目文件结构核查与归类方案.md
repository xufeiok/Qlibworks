## 三、目标结构（对标业界 Python 工程规范：src-layout + 薄入口层）

```
E:\Quant\Qlibworks\
├── src/qlworks/            # 库代码（现状良好，不动）
│   ├── evaluation/         #   评测核心（factor_stats/deep_eval/runner/...）
│   ├── factors/  features/ models/ backtest/ data/ live/ processors/
├── scripts/                # 命令行入口（薄层，只放可运行脚本）
│   ├── training/           #   factor_screen.py（唯一评测入口）train_tree-doubao.py train_linear.py
│   ├── evaluation/         #   batch_eval_4.py lifecycle_audit.py（批量编排）
│   ├── data/  backtest/  live/  registry/
│   └── _archive/           #   已废弃脚本（统一归档处）
├── tests/                  # 镜像 src 的单元测试（现状良好）
├── docs/                   # 正式文档（11 份保留）
│   └── _probes/            #   探针脚本/日志（可选归档，否则清理）
├── factor_data/            # 数据（现状基本良好）
│   ├── warehouse/  registry/  qualified_factors/  reports/  factor_library/
│   └── cache/              #   缓存目录合并为一个
├── runtime/                # ★新增：所有运行时产物统一收纳（gitignore）
│   ├── mlflow/  catboost/  logs/  debug/  backtest_out/
├── tools/                  # 一次性运维工具（现状良好）
├── configs/                # ★可选：yaml 配置（现散在 scripts/training/configs/）
└── 根级只保留：pyproject.toml uv.lock .gitignore .env AGENTS.md CLAUDE.md README.md
```

**归类原则**：
1. **可执行入口**（有 `if __name__ == "__main__"` 或 CLI）→ `scripts/` 按领域分子目录
2. **可复用逻辑** → `src/qlworks/` 包（一个函数只在一处）
3. **运行时产物**（模型、日志、实验库、回测 json、探针）→ `runtime/`，gitignore
4. **数据/注册表/配置** → `factor_data/` 或 `configs/`
5. **废弃** → `scripts/_archive/`（保留 git 历史，不删除）
