## 1. 执行摘要

### 1.1 四大家族专业度判定（一句话结论）



| 家族                | 专业度判定                           | 一句话理由                                                                                                                                                  |
| ----------------- | ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **quality（质量）**   | **基本够，但口径有偏**                   | IC/ICIR 门槛方向对，但裸 IC 未做行业中性、未识别慢变量特性、未开 crowding 监控，QMJ/MSCI 的 sector-relative 与防御属性钩子全部缺失                                                              |
| **value（价值）**     | **不足，且有方向性错误**                  | 最大缺口是 `factor_neutralization` 默认全关导致裸 IC 被银行 / 公用事业行业暴露主导；同时 0.60 年度同号率对价值这种有 12 年回撤的家族过严，周频 IC≥0.015 又偏松（中证月度 0.059–0.072 折算周频应 ≈0.025）               |
| **sentiment（情绪）** | **严重不足，且配置错配导致家族空转（当前因子数 = 0）** | 把给基本面因子设计的 "分年度 IC 同号占比≥0.60" 硬套在 regime-dependent 的情绪因子上，与 Stambaugh-Yu-Yuan (2012) 证明的 "高情绪期贡献 70–80% 利润、低情绪期不赚" 直接冲突；且缺事件窗口、净 IC（成本调整）、最小样本长度三个必备钩子 |
| **risk（风险）**      | **范式方向正确，但钩子太粗**                | "IC/ICIR/win\_rate 不强制、只查 risk\_rank" 方向对（风险因子≠alpha 因子），但只查 risk\_rank 一个开关，缺分层分离度、rolling 稳定性、下行保护、方向一致性四个机构必备维度                                     |

### 1.2 最高信号发现（含具体数字）



1. **sentiment 家族当前 = 0 因子，很可能不是没挖到 alpha，而是被错配的 cross\_regime 卡掉**：SYU 2012 证明高情绪月比低情绪月多赚 93 bp / 月（t=4.25），高情绪月贡献 80% 原始利润 / 70% 基准调整后利润 —— 要求 "分年度 IC 同号≥0.60" 等于要求情绪因子在低情绪期也有效，这与文献结论直接冲突（来源：Stambaugh-Yu-Yuan 2012, JFE 104 (2)）。

2. **value 家族裸 IC 被行业暴露污染**：中证指数 (2025.12) 实测 A 股价值因子月度 RankIC 全市场 0.072，但金融行业单行业贡献 0.15（vs 通信服务仅 0.05）——Qlibworks `factor_neutralization` 默认全关，裸 IC 0.015 可能主要来自银行 + 地产破净暴露（申万银行 PB 0.56，42 家银行仅 2 家 PB>1）。

3. **quality 家族 ICIR≥0.35 对慢变量而言偏高、对显著性而言偏低**：QMJ 美国全期 Sharpe 仅 0.40、三个子区间 Sharpe 0.34/0.50/0.37 全部为正但不高（Asness-Frazzini-Pedersen 2019, JFE），质量是慢变量，单期 IC 低但持续；现状既没有 52 周 rolling 持续性钩子，也没有行业中性化。

4. **risk 家族缺 "方向一致性" 校验是隐患**：Ang 2006 证明 IVOL 五分位 FF-3 α 从 Q1=0.11% 单调降到 Q5=−1.27%/ 月（t=−7.54），Amihud 2002 证明 ILLIQ 与预期收益正相关 —— 两者方向相反但都是有效风险因子；Qlibworks 现状若某波动率因子持续正 IC，不会报警。

5. **引擎通用配置中&#x20;**`permutation_test / monotonicity / factor_neutralization`**&#x20;默认全关，对 value/quality 两大家族是硬伤**：MSCI Quality / Barra CNE5 方法论都是 sector-relative z-score + ±3 winsorize + 带约束 WLS 行业中性回归，Qlibworks 把这三项全关等于裸跑。

**核心结论**：Qlibworks 现状用一套 IC/ICIR/win\_rate/cross\_regime=0.60 的统一门槛套四大家族，是把 "基本面慢变量 / 价值周期因子 / 情绪 regime 依赖因子 / 风险约束因子" 四种本质不同的因子混为一谈。sentiment 家族当前 = 0 就是一刀切的直接代价。
